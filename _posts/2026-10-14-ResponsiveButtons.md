Description of Responsive Buttons Project:
This project consisted of writing a code that turned on a different LED every time a button was pressed. However, since I snapped off my
button on my Lilypad, I incorporated an extra switch. The LEDs I chose were the onboard ones labeled 15-20. The same LED is on as
long as the button is held.

Three Tips:
1. It was a little tough figuring out how to utilize the switch, and, because I realized late that I should've built my code around a switch and
   not a button, the code wasn't working for a while. I should check the wiring first and make sure I know what my pins are connected to next time.

2. I was frustrated as to why my code wasn't working the way I wanted it to, but I needed to read through the assignment more carefully.
   was mixing up my onboard and offboard LEDs.

3. To make it easier to debug later on, I can definitely work on just testing one component at a time.
