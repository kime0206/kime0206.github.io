Description of Ghost Detector Assignment:
This code turns on all the Red LEDs when it is dark and cold.

Tip:
I think I should've tested each individual sensor out before trying to write the code for this assignment. It was hard
isolating and troubleshooting the issue when I couldn't figure out which connection point was the issue.

---
Description of Simultaneous Fireflies:
This project is a combination of the past three projects (i.e. Big Dipper, Flash Bulb, and Blue Ghost). The code itself programs
3 sets of LEDs to light with 3 different blinking patterns, in a single file, simulating parallel behaviors.

Tip:
My first approach was to try to compile everything at once. However, I think the better way to go about this project would have been to
break it down into smaller sections especially because you are literally combining 3 different projects into one.
